## 🔬 Interpolação de Craig (PPR-3)

### Teoria
Dadas fórmulas A e B tais que A ∧ B é UNSAT, a **interpolação de Craig** encontra uma fórmula I tal que:
1. A ⇒ I
2. I ∧ B ⇒ False
3. I usa apenas símbolos comuns a A e B

### Implementação Z3
```python
from z3 import *

def craig_interpolation(A, B):
    """
    A: fórmula fonte (teoria mais forte, ex: T1)
    B: fórmula alvo (teoria mais fraca, ex: T0)

    """
    # Z3 usa prova + interpolação
    s = Solver()
    s.set("proof", True)

    # A ∧ B
    s.add(And(A, B))
```

## 📊 Hardness Measurement via Z3

### Sistemas de Prova Suportados

| Sistema | Z3 Config | Descrição |
|---------|-----------|-----------|
| **Resolution** | `s.set("proof", True)` | Resolução padrão |
| **Extended_Frege** | `s.set("proof", True)` + let bindings | Com variáveis de extensão |
| **Frege** | `s.set("proof", True)` | Sem extensões |
| **P_Optimal** | Teórico | Bounds lineares |

```python
def measure_resolution_proof(self, sigma, n, b, is_T1):
    s = Solver()
    s.set("proof", True)
    # ... build formula ...
    result = s.check()
    if result == unsat:
        proof = s.proof()
        proof_str = str(proof)
        length = len(proof_str)
        resolutions = proof_str.count("resolution")
        return {"proof_length": length, "resolutions": resolutions}
    return {"proof_length": 0, "resolutions": 0}
```

## 🔬 Interpolação Manual para τ-formulas

Para τ-formulas (baseadas no gerador g_T), a interpolação pode ser construída analiticamente:

### Estrutura τ(g_T)_b
```
τ(g_n)_b ≡ ¬∃x. g_n(x) = b
        ≡ ∀x. g_n(x) ≠ b
```

### Interpolação entre T0 e T1
- **T0 = PA**: w* (Con) não coberto → τ é UNSAT para b com prefixo w*
- **T1 = PA+RFN**: w* coberto → τ é SAT para mesmo b

**Interpolação**: A estrutura do gerador permite construir I explicitamente:
- I = "b tem prefixo w*" (para b fora da imagem de g_T0)
- Tamanho: O(log n) bits
